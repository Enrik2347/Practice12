# Практична робота №6. Робота з текстовими файлами

Консольний проєкт C# (.NET 8) до практичної роботи №6 з дисципліни
«Основи програмування».

## Що реалізовано

**Рівень А**

1. `SaveTemperatures` / `LoadTemperatures` — запис і читання 12 середньомісячних температур.
2. `AppendNote` — дописування нотатки з датою й часом.
3. `CountLines` — кількість непорожніх рядків; `-1`, якщо файлу немає.
4. `CopyWithNumbers` — копія файлу з нумерацією рядків.

**Рівень Б**

5. `AddExpense`, `TotalByCategory`, `MonthlyReport` — облік витрат із підтримкою
   коми в сумі та пропусканням зіпсованих рядків.

**Самостійна робота**

1. `LongestLine` — найдовший рядок, читання через `StreamReader`.
2. `MergeFiles` — злиття кількох файлів із роздільниками та списком пропущених.
3. `WordFrequency` — топ-10 найчастіших слів через `Dictionary<string, int>`.

## Запуск

```powershell
dotnet run
```

Файли створюються в робочій папці програми `bin\Debug\net8.0`. Повний шлях
друкується на початку роботи програми.
